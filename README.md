# Customer_Behavior_Analysis
End-to-end Customer Shopping Behavior Analysis (3,900 transactions) using Python, PostgreSQL, and Power BI. Includes an executive presentation deck and actionable business recommendations.

## 📌 Project Overview
This project presents an end-to-end data analytics workflow examining *3,900 customer shopping transactions* across 18 demographic and purchasing attributes. The primary objective is to analyze customer spending patterns, evaluate discount and subscription performance, and translate database findings into strategic recommendations for leadership and marketing teams.

---

## 🛠️ Tech Stack & Tools
- *Python (Pandas, NumPy):* Data cleaning, missing value imputation, and feature engineering.
- *PostgreSQL:* Relational database setup, structured queries, CTEs, and customer segmentation logic.
- *Power BI:* Interactive visual dashboard tracking revenue, demographic segments, and fulfillment preferences.
- *Gamma:* AI-assisted executive presentation deck generation for business stakeholders.
